# Screenshots

Every image in this directory is **staged**: generated against an isolated server
with invented accounts and invented conversations, for documentation only. No
screenshot in this repository shows a real user, a real username, or a real
message. The pilot's actual accounts and conversations exist only in a private
archive and are not published — which is the same commitment the paper makes.

The interface is Turkish: the pilot was a Turkish-speaking group, and the strings
were never internationalized. That is a real limitation, recorded rather than hidden.
